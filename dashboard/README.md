# 📊 Dashboard Documentation

## 📌 Dashboard Overview

This Power BI dashboard was developed to analyze supermarket business performance using transactional sales data.

The report focuses on:

- Revenue analysis
- Customer purchasing behavior
- Product line performance
- Payment method analysis
- Branch performance
- Customer satisfaction
- Average Order Value (AOV)
- Quantity purchasing trends

The dashboard was designed using a business-oriented analytical approach to support data-driven decision-making.

---

# 📊 Main KPIs

The dashboard includes the following key business metrics:

| KPI | Description |
|---|---|
| Total Revenue | Total sales generated |
| Total Invoice | Total number of transactions |
| Total Quantity | Total quantity sold |
| Revenue Growth Rate (%) | Monthly revenue growth |
| Average Order Value (AOV) | Revenue per invoice |
| Average Quantity per Invoice (AQI) | Quantity sold per invoice |
| Average Rating | Customer satisfaction level |

---

# 🧠 DAX Measures Used

---

## General Measures

| Measure | Purpose |
|---|---|
| Total Revenue | Calculates total business revenue |
| Total Invoice | Calculates total transaction count |
| Total Quantity | Calculates total quantity sold |
| Previous Revenue | Retrieves previous period revenue |
| Revenue Growth Rate (%) | Measures revenue growth over time |
| Average Order Value | Calculates revenue per invoice |
| Average Quantity per Invoice | Calculates quantity sold per invoice |
| Average Rating | Calculates average customer rating |
